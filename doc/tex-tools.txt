*tex-tools.txt*  LaTeX editing with Tree-sitter and LSP

Structural edits, text objects, navigation, tables and optional conceal.
Requires Neovim 0.11+ and the `latex` Tree-sitter parser. Follow links with
CTRL-]; return with CTRL-T.

  |tex-tools-setup|              Configuration and defaults
  |tex-tools-mappings|           Keys and custom mappings
  |tex-tools-commands|           Editing commands
  |tex-tools-textobjects|        Text objects and counts
  |tex-tools-navigation|         Motions and jump history
  |tex-tools-tables|             Tables and matrices
  |tex-tools-section-levels|     Promote/demote headings
  |tex-tools-outline|            File and project outline
  |tex-tools-build|              Build, logs and cleanup
  |tex-tools-compiler-profiles|  Switch compilers
  |tex-tools-viewer|             PDF viewing and inverse search
  |tex-tools-conceal|            Render LaTeX symbols
  |tex-tools-api|                Lua API and snippet queries
  |tex-tools-health|             Troubleshooting and development

==============================================================================
SETUP                                                        *tex-tools-setup*

Install the parser separately (e.g. `:TSInstall latex`), then call: >lua

    require('tex-tools').setup({
      mappings = true,
      overwrite_mappings = false,
      smart_enter = false,
      conceal = false,
      math_environments = {},
    })
<
Commands and buffer-local mappings attach to `tex/plaintex` buffers. Set
`vim.g.maplocalleader` before loading. Configure the selected language server
and toolchain in your LSP setup.
Local structural editing needs only the parser.

Options and defaults ~
  `lsp`                 `'texlab'`; or `'texquill'`
  `mappings`            `true`; false keeps commands and <Plug> mappings
  `overwrite_mappings`  `false`; preserve existing global/local keys
  `smart_enter`         `false`; list-aware Insert <CR>, requires mappings
  `conceal`             `false`; true or a table, see |tex-tools-conceal|
  `math_environments`   `{}`; extra math environment names, including stars
  `build.output_lines`  `2000`; positive live-output line limit
  `build.main_file`     `false`; main path relative to the LSP root
  `build.profiles`      `{}`; see |tex-tools-compiler-profiles|
  `viewer`              see |tex-tools-viewer|

`overwrite_mappings=true` replaces conflicting default keys, including <CR>.
Disabling it or default mappings restores replaced local mappings and reveals
current global keys. Keys changed/deleted after attachment are preserved.

MAPPINGS                                                  *tex-tools-mappings*

Normal mode; every `l...` key below has the <LocalLeader> prefix. The action
column is the suffix in `<Plug>(TexTools{Action})`.

  Key             Action ~
  `lcr` / `lcd`   RenameCommand / UnwrapCommand
  `lcs`           SurroundCommand (also Visual)
  `ler` / `let`   RenameEnvironment / ToggleEnvironmentStar
  `les` / `led`   SurroundEnvironment (also Visual) / UnwrapEnvironment
  `lm`            JumpEnvironment
  `lf`            ToggleMathDelimiters
  `ldc` / `ldd`   ChangeMathDelimiters / UnwrapMathDelimiters
  `ldt` / `ldm`   ToggleMathDelimiterSize / JumpMathDelimiter
  `li` / `lt`     InsertItem / Outline
  `ll` / `lv`     Build / ForwardSearch
  `lk` / `lK`     CancelBuild / CancelAllBuilds
  `lg`            BuildStatus
  `lo` / `lq`     BuildOutput / Log
  `le`            Errors
  `lc` / `lC`     Clean / CleanFull
  `]]` / `[[`    NextSection / PreviousSection
  `]i` / `[i`    NextItem / PreviousItem
  `]e` / `[e`    NextEnvironment / PreviousEnvironment
  `]m` / `[m`    NextMath / PreviousMath
  `]t` / `[t`    NextCell / PreviousCell

Insert `]]` uses `<Plug>(TexToolsCloseDelimiter)`; optional <CR> uses
`<Plug>(TexToolsSmartEnter)`. Other commands have no default key.
Text-object <Plug> names use `Around`/`Inside` + `Environment`, `Command`,
`Argument`, `Math`, `MathDelimiter`, `Item`, `Section` or `Cell`.
>lua

    vim.keymap.set('n', '<LocalLeader>lr',
      '<Plug>(TexToolsRenameEnvironment)')
    vim.keymap.set({ 'x', 'o' }, 'aE', '<Plug>(TexToolsAroundEnvironment)')
<

EDITING COMMANDS                                          *tex-tools-commands*
                                                     *tex-tools-extra-editing*

Omitted names/shapes prompt. Cancelling or editing the target buffer while a
prompt is open cancels the operation. Names omit the backslash.

`:TexToolsRenameCommand` [name]                       *:TexToolsRenameCommand*
    Rename one invocation, preserving arguments/options.
`:TexToolsUnwrapCommand`                              *:TexToolsUnwrapCommand*
    Remove a command with exactly one braced argument and no options.
`:[range]TexToolsSurroundCommand` [name]            *:TexToolsSurroundCommand*
    Wrap lines in \name{...}; Visual mode wraps the exact selection.
`:TexToolsToggleCommandStar`                      *:TexToolsToggleCommandStar*
    Toggle the command's trailing star.

`:TexToolsRenameEnvironment` [name]               *:TexToolsRenameEnvironment*
    Rename both markers of the innermost environment.
`:TexToolsToggleEnvironmentStar`              *:TexToolsToggleEnvironmentStar*
    Toggle a trailing star on both markers.
`:[range]TexToolsSurroundEnvironment` [name]    *:TexToolsSurroundEnvironment*
    Wrap whole lines, preserving body indentation.
`:TexToolsUnwrapEnvironment`                      *:TexToolsUnwrapEnvironment*
    Remove markers and begin options; keep the body.
`:TexToolsJumpEnvironment`                          *:TexToolsJumpEnvironment*
    Jump from begin/body to end, or end to begin.

`:TexToolsToggleMathDelimiters`                *:TexToolsToggleMathDelimiters*
    Switch `$...$` / `\(...\)` or `$$...$$` / `\[...\]`.
`:TexToolsChangeMathDelimiters` [shape]        *:TexToolsChangeMathDelimiters*
    Change both brackets; keep sizing and body. See |tex-tools-math-brackets|.
`:TexToolsUnwrapMathDelimiters`                *:TexToolsUnwrapMathDelimiters*
    Remove brackets, preserving contents.
`:TexToolsToggleMathDelimiterSize`          *:TexToolsToggleMathDelimiterSize*
    Add/remove `\left` and `\right`.
`:[count]TexToolsJumpMathDelimiter`               *:TexToolsJumpMathDelimiter*
    Jump to the matching bracket; count selects enclosing depth.
`:TexToolsToggleFraction`                            *:TexToolsToggleFraction*
    Convert `a/b` to/from `\frac{a}{b}`; brace compound operands.
`:TexToolsConvertMath` {target}                         *:TexToolsConvertMath*
    Convert a formula: `inline`, `display`, `equation[*]`, `align[*]`,
    `gather[*]`, `multline[*]`, `math`, `displaymath` or a custom math name.
`:TexToolsToggleMathMode`                            *:TexToolsToggleMathMode*
    Switch inline/display. Inline needs one line without comments/labels/tags;
    columns and row breaks require `align[*]`.
`:TexToolsCloseDelimiter`                            *:TexToolsCloseDelimiter*
    Insert the nearest missing closing marker. Insert `]]` falls back to
    literal text when unsafe or already closed.
`:TexToolsInsertItem`                                    *:TexToolsInsertItem*
    Insert a sibling after the whole item and enter Insert mode; create the
    first item in an empty list. Supports itemize/enumerate/description.

                                                   *tex-tools-command-editing*
Editing rules ~
Command names: ASCII letters/@, optional trailing star. Environment names may
also contain digits, underscores and hyphens. Blockwise/partial-structure
surrounds and edits that merge control words are refused. Ambiguous fractions,
comments, literal content and definitions are protected.

                                                     *tex-tools-math-brackets*
Math brackets ~
  Shape       Alias       Pair ~
  `paren`     `(`         `( )`
  `bracket`   `[`         `[ ]`
  `brace`     `{`         `\{ \}`
  `angle`     `<`         `\langle \rangle`
  `vert`      `|`         `\lvert \rvert`
  `Vert`      `\|`        `\lVert \rVert`

Plain directional and `\left` / `\right` pairs work in math. Sized pairs may use
mixed/invisible markers; toggling size needs matching visible markers. Plain
symmetric bars, fixed sizes and custom macros are excluded. Sizing cannot
cross alignment cells/rows; unwrap rejects orphaned `\middle` and marker
comments. Jumps land on sizing commands where present.

                                                       *tex-tools-smart-enter*
List Enter ~
`smart_enter=true` splits a nonempty item at the cursor, keeping its suffix
and nested content. Empty/unsupported contexts use native Enter. One undo
removes the insertion and immediately typed text. For completion integration,
call |tex-tools.smart_enter()| in its fallback branch.

                                                            *tex-tools-repeat*
Repeat ~
Cursor-based rename, unwrap, star toggles, math edits and conversions support
|.|, reusing prompt answers. `[count].` stops at an invalid target and shares
one undo. Surrounds/list input do not register structural repeats. Failed
edits preserve the previous repeat; API edits register it only in the current
buffer in Normal mode. Text-object operators keep native repeats.

==============================================================================
TEXT OBJECTS                                           *tex-tools-textobjects*

Visual/operator-pending mode; e.g. `dai`, `cii`, `y2ia`.

  Around / inside   Target / inner selection ~
  `ae` / `ie`       Environment / body without options or marker lines
  `ac` / `ic`       Command call / name without backslash, including star
  `aa` / `ia`       Curly or bracket group / contents
  `a$` / `i$`       Formula or math environment / body
  `ad` / `id`       Math brackets with sizing / contents
  `ai` / `ii`       List item with marker/label / trimmed body
  `aP` / `iP`       Section and descendants / without heading
  `at` / `it`       Table cell / without edge whitespace

Counts climb enclosing objects of the same kind; `2d2ac` selects depth four.
Sections climb heading levels; cells accept only count 1. Empty inner objects
or missing depths cancel without changing text, registers or the prior repeat.
Item objects stay at the nearest list level (`2ai` selects its parent); blank
gaps use the preceding item. Whole-line `ai` is linewise, including its final
newline/trailing comment, but excluding following blank/comment lines.

NAVIGATION                                              *tex-tools-navigation*

`:[count]TexToolsNextSection`                           *:TexToolsNextSection*
`:[count]TexToolsPreviousSection`                   *:TexToolsPreviousSection*
`:[count]TexToolsNextItem`                                 *:TexToolsNextItem*
`:[count]TexToolsPreviousItem`                         *:TexToolsPreviousItem*
`:[count]TexToolsNextEnvironment`                   *:TexToolsNextEnvironment*
`:[count]TexToolsPreviousEnvironment`           *:TexToolsPreviousEnvironment*
`:[count]TexToolsNextMath`                                 *:TexToolsNextMath*
`:[count]TexToolsPreviousMath`                         *:TexToolsPreviousMath*

Motions visit opening markers in source order; items stay at the current list
level, skipping nested lists. Counts stop at the furthest target without
wrapping. Successful jumps record history and open folds; no target leaves the
cursor unchanged. Normal mode only; unmodifiable buffers work. Comments,
literal content and parser-recognized definitions are skipped.

TABLES AND MATRICES                                         *tex-tools-tables*

`:[count]TexToolsNextCell`                                 *:TexToolsNextCell*
`:[count]TexToolsPreviousCell`                         *:TexToolsPreviousCell*
    Visit cells in row-major order. See |tex-tools.in_table_cell()|.
`:TexToolsInsertRow` / `:TexToolsDeleteRow`               *:TexToolsInsertRow*
                                                          *:TexToolsDeleteRow*
    Insert an empty row after the current row, or delete the current row.
`:TexToolsInsertColumn` / `:TexToolsDeleteColumn`      *:TexToolsInsertColumn*
                                                       *:TexToolsDeleteColumn*
    Insert after the current column (copy alignment), or delete that column.
    Update plain `l/c/r/X` preambles; matrices need none. Alignment/cases
    column edits and complex preambles are unsupported.

Edits need equal-width rows on separate source lines; comments, rules, spans
and nested environments are refused. The last row/column cannot be deleted.
Row-break options stay. Dot repeat and one-step undo work. Navigation/text
objects accept complex content in the nearest supported environment.

SECTION LEVELS                                      *tex-tools-section-levels*

`:[count]TexToolsPromoteSection`                     *:TexToolsPromoteSection*
`:[count]TexToolsDemoteSection`                       *:TexToolsDemoteSection*
    Shift the current section and descendants by count levels (default 1).
    Order: part, chapter, section, subsection, subsubsection, paragraph,
    subparagraph. The document class must support the resulting commands.

Stars, short titles, labels and body stay. Overflow/incomplete headings cancel
the whole edit. Only this buffer changes; dot repeat and single-step undo
work.

==============================================================================
OUTLINE                                                    *tex-tools-outline*

`:TexToolsOutline[!]` [query]                               *:TexToolsOutline*
    Open a searchable section split; `!` expands the main file's literal
    input/include files in source order. Texlab is optional. Main selection
    follows |:TexToolsMain|, `build.main_file` and root directives.

  `<CR>` jump   `/` search   `f` filter title/path   `r` refresh   `q` close

The panel shows hierarchy, stars and file:line; short titles are preferred.
`>` marks the current section. Empty filters clear; query sets the initial
filter. Modified buffers are read without saving and preserved on jumps.
Includes resolve from the compilation directory, then the including file.
Cycles/missing/nonliteral includes warn. Macros, conditionals, includeonly and
TEXINPUTS are not evaluated. Per refresh: 256 file visits, 32 nested includes,
2 MiB per disk file, 8 MiB total; exceeding a limit returns an error.

With texquill, headings come from `textDocument/documentSymbol`; `!` uses
server root selection and follows local .tex `documentLink` targets in source
order. No local TeX parsing or include resolution is used for this outline.
Titles/ranges follow the server. Limits: 256 file visits, 32 nested includes;
cyclic or failed includes warn. A selected texquill client is required.

BUILD, LOGS AND CLEANUP                                      *tex-tools-build*

Requires an attached, separately configured client selected by `lsp`.
Texlab remains the default. With `lsp = 'texquill'`, configure the Neovim
client name as `texquill`; the plugin does not start servers
or fall back to another backend. Use `cmd = { 'texquill', '--stdio' }`.
Server settings use `init_options` or `settings.latex` (also unwrapped).

`:TexToolsBuild`                                              *:TexToolsBuild*
    Save current/main buffers with `:update`, then build the resolved main.
`:TexToolsMain` [path/select/reset]                            *:TexToolsMain*
    Show/select/reset the main for this client/session; paths use the LSP
    root. Reset restores `build.main_file` or source/root-directive discovery.
`:TexToolsInfo`                                                *:TexToolsInfo*
    Show main, compiler, working directory and artifact paths.
`:TexToolsCancelBuild`                                  *:TexToolsCancelBuild*
    Cancel the current project build (texlab: current server instance).
`:TexToolsCancelAllBuilds`                          *:TexToolsCancelAllBuilds*
    Cancel builds in every running instance of the selected backend.
`:TexToolsBuildStatus`                                  *:TexToolsBuildStatus*
    Show build state, elapsed time, on-save setting and current compiler.
`:TexToolsBuildOnSave` [on/off/toggle]                  *:TexToolsBuildOnSave*
    Change this client's session setting; no argument toggles.
`:TexToolsBuildOutput`                                  *:TexToolsBuildOutput*
    Open read-only live output. `q` closes; `F` toggles following. Resets each
    build; capped by `build.output_lines`.
`:TexToolsLog` [path]                                           *:TexToolsLog*
    Open a full read-only log. An explicit path needs no LSP client.
`:TexToolsErrors[!]`                                         *:TexToolsErrors*
    Fill/open quickfix with this client's diagnostics; `!` shows errors only.
    Output/log/diagnostic windows do not open automatically after compilation.
`:TexToolsClean`                                              *:TexToolsClean*
    Remove auxiliary artifacts for the resolved main.
`:TexToolsCleanFull`                                      *:TexToolsCleanFull*
    Also remove the PDF. Refuse cleanup during compilation/another cleanup.

Texlab build behavior ~
Manual builds use the selected main; automatic builds keep texlab's dependency
root. Save a modified child first or disable `build.onSave` before building
another main. A save-triggered build does not also send a manual request. One
manual build per client; native |LspProgress| handlers are preserved.
Automatic progress completion does not imply success. A failed compiler may
leave an incomplete PDF. Status refers to the last build; compiler/profile
refer to current settings. Main/compiler changes are refused during builds or
cleanup. No independent `latexmk -pvc` or region compilation is provided.

Texlab artifact discovery ~
Resolve main via root directives, `build.main_file` or `\documentclass`;
ambiguous roots fail. Output/jobname arguments and explicit texlab directories
are respected. Latexmk's `-dir-report-only` discovers `.latexmkrc`/`-r` paths;
other backends may need explicit directories. Discovered log directories sync
to texlab on attachment, TeX buffer changes and rc saves; explicit overrides
stay. Omit `-file-line-error` for texlab diagnostics, then rebuild old logs.

Texlab cleanup ~
Latexmk uses texlab clean requests. Tectonic compile removes exact auxiliary
files, retaining source, bibliography, `.bbl` and unrelated files; full adds
the PDF. No directory recursion; leaf symlinks are unlinked. Tectonic project
build/watch and unsupported compilers return errors.

Latex-lsp behavior ~
Build, cancel, status and cleanup call `latex.build`, `latex.cancelBuild`,
`latex.buildStatus`, `latex.cleanAuxiliary` and `latex.cleanArtifacts`.
The server owns dependency/root discovery, artifact paths, build concurrency,
cleanup safety and diagnostics. This backend never probes latexmk itself.
Build saves the current buffer; save other modified dependencies first.
On-save builds use the server's `build.onSave`. Main selection updates its
`build.rootFile`; reset clears it. `build.main_file` sets the initial
override.
Server project files may override these client defaults.

Info/log/view use the root and PDF/log URIs reported by the server. Artifact
paths may be absent before a completed build or after cleanup. Output shows
its completion summary (not a live compiler stream); existing notification
handlers are preserved. Status and project queries wait up to two seconds
per LSP request. Builds and SyncTeX commands run asynchronously.

COMPILER PROFILES                                *tex-tools-compiler-profiles*

`:TexToolsCompiler` [name/toggle]                          *:TexToolsCompiler*
    Show compiler/profile, switch to name, or cycle alphabetically.
    Completion is available; unmatched settings start at the first name.
>lua

    require('tex-tools').setup({ build = { profiles = {
      latexmk = {
        executable = 'latexmk',
        args = { '-pdf', '-synctex=1', '-interaction=nonstopmode', '%f' },
      },
      tectonic = {
        executable = 'tectonic',
        args = { '-X', 'compile', '%f', '--synctex', '--keep-logs',
                 '--keep-intermediates' },
      },
    } } })
<
Names use ASCII letters/digits/underscore/dot/hyphen, starting with a letter,
digit or underscore; `toggle` is reserved. Required: `executable`, `args`.
Optional: `auxDirectory`, `logDirectory`, `pdfDirectory`, `filename`
(basename). Switching replaces all six fields, clearing omitted overrides;
repeat shared paths in each profile and pass the compiler's output arguments
too. Use `-xelatex` instead of `-pdf` for XeLaTeX.

Switching checks the executable and sends `workspace/didChangeConfiguration`;
it neither restarts texlab nor builds. Sending failure rolls back local state;
success means sent, with asynchronous server application. Other LSP settings
stay. All buffers sharing the client see changes; files are never rewritten.
`setup()` only defines profiles; your LSP setup chooses the initial compiler.

Latex-lsp profiles use native server keys instead: required `executable`;
optional `arguments`, `engine`, `outputDirectory`, `auxiliaryDirectory`,
`finalOutputDirectory`, `jobName`. Omitted fields reset to server defaults.
Arguments accept server placeholders `%f`, `%o`, `%j`. Example:
>lua
    require('tex-tools').setup({
      lsp = 'texquill',
      build = { profiles = {
        latexmk = { executable = 'latexmk', engine = 'xelatex' },
        direct = { executable = 'xelatex', outputDirectory = 'build' },
      } },
    })
<
Validation and effective project configuration belong to the server.
Profile matching describes client settings; project files may override them.

PDF VIEWING AND INVERSE SEARCH                              *tex-tools-viewer*

`:TexToolsView`                                                *:TexToolsView*
    Open the resolved PDF without a source jump; requires the selected LSP.
`:TexToolsForwardSearch`                              *:TexToolsForwardSearch*
    Jump the PDF to the cursor without saving; requires configured SyncTeX.
`:TexToolsInverseSearch` [skim|zathura]               *:TexToolsInverseSearch*
    Show a stable callback. For Skim, copy Command/Arguments into Settings >
    Sync > Custom once. Zathura launched via View receives it automatically.

Viewer defaults ~
  `viewer.method`      `'auto'`; also `skim`, `zathura`, `generic`
  `viewer.executable`  `false`; executable override (Skim overrides `open`)
  `viewer.args`        `{}`; extra argv entries before the PDF path
  `viewer.focus`      `true`; let Skim take focus on View/texquill search

Auto detects Skim via texlab displayline, then Zathura via texlab/PATH, then
the system opener. Generic openers do not configure synchronization. Viewing
needs no SyncTeX file; synchronized search requires compiler/viewer support
(Tectonic: `--synctex`). Forward search uses texlab settings; explicit mains
or discovered latexmk paths expand `%p` (PDF), `%f` (source), `%l` (line)
directly as argv entries.

With texquill, `latex.forwardSearch` returns page/coordinates. Skim receives
them through AppleScript, waits for startup, and shows its native source-line
indicator. Set `viewer.focus = false` to keep focus in Neovim. This option
controls Skim View and texquill forward search; texlab forward search uses
its own executable/args. Early texquill searches wait up to 10 seconds for
LspAttach, retaining the source position. Zathura opens the returned page.
Auto detects Skim in /Applications, then Zathura. Configure Skim/Zathura for
forward search; generic viewers support View only. The plugin does not run
SyncTeX again.
The Lua `inverse_search_position(page, x, y)` API calls `latex.inverseSearch`
and jumps to the first returned source location. PDF pages are one-based;
coordinates are points measured from the top left. Existing source-file
callbacks work with both backends.

Callbacks survive Neovim restarts; open a local TeX file to register a
session. Regenerate after executable/plugin/cache path or NVIM_APPNAME
changes. Native macOS/Linux routing prefers a loaded source, then matching
workspace, then recent activity. Records live under
`stdpath('cache')/tex-tools/inverse-search`; viewer/editor must share
registry/socket access. No extra plugin is needed. The `User
TexToolsInverseSearch` event carries file/line/column; terminal activation can
be configured there. Viewer preferences are not auto-modified.

CONCEAL                                                    *tex-tools-conceal*

Opt in; native 'conceallevel' / 'concealcursor' control display: >lua

    require('tex-tools').setup({
      conceal = { symbols = { alpha = 'Α', beta = false, RR = 'ℝ' } },
    })
    vim.opt.conceallevel = 2
    vim.opt.concealcursor = 'nc' -- Optional: conceal on the cursor line.
<
Categories (all true when enabled) ~
  `accents`          Single-letter accents: `\'{e}` -> é, `\"o` -> ö
  `ligatures`        `\ae{}`, `\OE{}`, `\ss{}`, dashes and quotes
  `cites`            Hide command/notes; keep keys in [] or ()
  `fancy`            Dots, `\colon`, `\slash`, `\_`, `\item`
  `spacing`          Hide spacing/phantom macros; `~` becomes a space
  `math_bounds`      Hide matched formula markers
  `math_delimiters`  Hide sizing commands; render bracket macros
  `styles`           Hide text/math style wrappers, retaining body/colors
  `math_symbols`     Greek letters, operators, relations, sets and arrows

Set a category false to disable it; `conceal=false` or `{enabled=false}`
disables rendering. `symbols` maps bare ASCII-letter/@ command names to one
printable Unicode character, or false; disabling `math_symbols` disables both
built-in/custom symbols. See `lua/tex-tools/conceal_symbols.lua` for defaults.

Fractions, scripts, headings and unknown constructs stay source. Math symbols
are math-only; text accents/ligatures apply in math only inside `\text{...}`.
Comments, literals, definitions, paths, labels and citation-key spelling are
protected. No macro expansion or font emulation. Buffer text and window
options stay unchanged; disable overlapping legacy/VimTeX conceal rules.
Visible-line rendering is cached; pending/missing parses retain source.
`conceal.max_line_length=10000` caps bytes per line; 0 removes the limit.

==============================================================================
LUA API                                                        *tex-tools-api*

Functions in `require('tex-tools')` are available without `setup()`.
Edits/jumps return `true` or `false, error`; omitted names may open async
prompts. Queries do not notify. Ranges are zero-based, byte-based,
end-exclusive:
`{start_row, start_byte, end_row, end_byte}`.
Query opts: `{bufnr, pos={row,col}}`;
default current cursor, explicit pos required for another buffer. Missing
parser/invalid positions return `false/nil, error`.

Context queries ~

`in_math([opts])`                                        *tex-tools.in_math()*
    Math, including custom environments; `\text{...}` suppresses outer math.
`in_comment([opts])`                                  *tex-tools.in_comment()*
    LaTeX comments, excluding literal/code content.
`in_subscript([opts])`                              *tex-tools.in_subscript()*
`in_superscript([opts])`                          *tex-tools.in_superscript()*
    Script payload, excluding operator/opening brace; include the insertion
    position before a closing brace, even in empty groups.
`in_numerator([opts])`                              *tex-tools.in_numerator()*
`in_denominator([opts])`                          *tex-tools.in_denominator()*
    Nearest `\frac` / `\dfrac` / `\tfrac` part with two complete braced arguments.
`in_table_cell([opts])`                            *tex-tools.in_table_cell()*
    Body cells in tabular[*]/tabularx, array, matrix (plain/p/b/B/v/V/small),
    cases,
    aligned/alignedat/align/alignat/flalign/split (including stars). Excludes
    headers, separators, row breaks and rules; nearest environment must be
    supported and complete. Spans/visual columns are not inferred.
`environment([opts])`                                *tex-tools.environment()*
    Table or `nil, error`: bufnr, name, node, begin_node, end_node,
    begin_name, end_name. Query again after edits.

Detailed math queries stop at the nearest formula; comments/literals suppress
them. Ordinary nonmatches return false. Macros are not expanded. Wrap queries
for LuaSnip so its arguments are not interpreted as opts: >lua

    local in_power = function()
      return require('tex-tools').in_superscript()
    end
<
Editing and navigation ~

`rename_command([name])`                          *tex-tools.rename_command()*
`unwrap_command()`                                *tex-tools.unwrap_command()*
`toggle_command_star()`                      *tex-tools.toggle_command_star()*
`rename_environment([name])`                  *tex-tools.rename_environment()*
`toggle_environment_star()`              *tex-tools.toggle_environment_star()*
`unwrap_environment()`                        *tex-tools.unwrap_environment()*
`toggle_math_delimiters()`                *tex-tools.toggle_math_delimiters()*
`change_math_delimiters([shape])`         *tex-tools.change_math_delimiters()*
`unwrap_math_delimiters()`                *tex-tools.unwrap_math_delimiters()*
`toggle_math_delimiter_size()`        *tex-tools.toggle_math_delimiter_size()*
`toggle_fraction()` / `convert_math(target)` / `toggle_math_mode()`
    Cursor-based counterparts of |tex-tools-commands|.
`surround_command([name [, opts]])`             *tex-tools.surround_command()*

Build and project ~

`build()`                                                  *tex-tools.build()*
`forward_search()`                                *tex-tools.forward_search()*
    `true, request_id` or `false, error`; asynchronous results notify.
`inverse_search_position(page, x, y)` *tex-tools.inverse_search_position()*
    Latex-lsp only: query PDF coordinates and jump to the first source result.
    Returns `true, request_id` or `false, error`; asynchronous errors notify.
`cancel_build()` / `cancel_all_builds()` / `build_on_save([boolean])`
    `boolean[, result_or_error]`; omitted on-save value toggles.
`build_status()`
    Snapshot or `nil, error`: phase, uri, on_save, elapsed, result/error when
    known, and current compiler/profile. Returned tables are copies.
    Latex-lsp queries `latex.buildStatus` and retains native response fields;
    phase uses native idle/running/success/error/cancelled/timeout strings.
    on_save reflects client settings; project configuration may override it.
`compiler([name])`                                      *tex-tools.compiler()*
    Query/switch (`'toggle'` cycles). `true, snapshot` or `false, error`;
    snapshot: profile, executable, args, sorted profiles. Matching compares
    all six fields; identical matches retain the selected name if possible.
`main_file([path])` / `project_info()`
    Main: `true, path` or `false, error`; false resets (path may be nil).
    Info: snapshot or `nil, error`.
`build_output()` / `build_log([path])` / `build_errors([opts])`
    `true, buffer/path/count` or `false, error`.
    Errors opts: errors_only=false, open=true; open=false only fills quickfix.
`clean([full])`
    `true, request_id` (latexmk), `true, removed_count` (Tectonic), or
    `false, error`; full defaults false.

Viewer and outline ~

`view()` / `inverse_search(file, line [, column])`
    View: `true, job_id` or `false, error`. Inverse: boolean/error; one-based
    line/byte column, preserving modified buffers.
`inverse_search_command(kind)`
    Table or `nil, error`: command, arguments, argv, shell_command, registry,
    server (informational). RPC starts on demand for local TeX sessions.
`outline([opts])`                                        *tex-tools.outline()*
    `true, panel_buffer` or `false, error`; opts: project=false, query=''.
`outline_entries([opts])`                        *tex-tools.outline_entries()*
    `{entries, warnings, root, project}` or `nil, error`; opts also accepts
    bufnr/pos. Entries: path, optional bufnr, zero-based row/col, level (1-7),
    kind, title, starred, optional current. No Tree-sitter nodes.
